# 🎯 Faceit Analytics

Аналитический сервис для игроков **FACEIT**: статистика профилей, **AI-анализ демо-файлов** (платная функция, первый разбор бесплатно), сравнение профилей по статистике, авторизация и защита от DDoS.

## Возможности

| Функция | Описание |
|---|---|
| 📊 Профиль игрока | Статистика CS2/L4D2/R6 с Faceit API: K/D, HS%, ADR, винрейт, последние матчи |
| 🧠 AI-анализ демо | Загрузка `.dem` → нейросеть разбирает аим, позиционирование, утилиту, экономику, клатчи; выдаёт рейтинг S–D и рекомендации |
| 📋 AI Training Plan | На основе анализа демо — персональный план прокачки на неделю: топ-3 приоритета, конкретные упражнения, объём, метрика успеха |
| 📈 Трекер прогресса | Снимки статистики во времени + интерактивные графики ECharts (Win Rate, K/D, HS%, ADR) с дельтами и наложением рейтингов из AI-анализов демо |
| 🔫 Статистика по оружию | K/D и HS% по каждой пушке (AK-47, M4A4, AWP…), основное оружие игрока |
| 🔮 Прогноз матча | Вероятность победы A vs B (логистическая модель на метриках) + разбивка, какие метрики решают исход |
| 🚩 Детект аномалий | Флаги подозрительно высоких значений (HS%, K/D, ADR, винрейт) — в духе CSWatch watchlist |
| 🎯 Еженедельные миссии | 6 миссий/неделю (победы, демо-анализы, сравнения, снимки) → очки → месячный топ-100; авто-сброс баланса; топ-5 месяца получают Faceit Premium (очередь активации по faceit_id); полный анти-абьюз |
| 💳 Платная модель | Первый анализ бесплатен, далее — 99 ₽/раз (настраивается) или безлимит на PRO-подписке |
| ⚔️ Сравнение профилей | Два faceit_id → таблица из 10 метрик с вердиктом «кто сильнее» |
| 🔐 Авторизация | Регистрация/вход, JWT-токены, bcrypt-хэши паролей |
| 🛡 Анти-DDoS | Sliding-window rate limiting по IP + математическая капча на входе (включается автоматически после 3 неудачных попыток) |
| ✉️ Контакты | Форма обратной связи + публичные контактные данные |

### Как работает AI-анализ демо

1. Пользователь загружает `.dem` + faceit_id + карту.
2. Бэкенд проверяет квоту: `free_demo_analyses_used < FREE_DEMO_ANALYSES` → бесплатно, иначе требуется `pay_token` (HTTP 402).
3. Метаданные матча + статистика игрока отправляются в движок анализа:
   - **локальный эвристический** (детерминированный, мгновенный, без внешних зависимостей);
   - **внешний LLM** (OpenAI-совместимый API), если заданы `AI_API_KEY`/`AI_BASE_URL`.
4. Результат: JSON с блоками `aim_analysis`, `positioning`, `utility`, `economy`, `clutches`, `strengths`, `weaknesses`, `recommendations`, `rating {score, letter}`. Сохраняется в БД, показывается в UI, попадает в историю.

### Система миссий и очков

1. **Каталог** — 6 миссий на ISO-неделю: победы (10/20), AI-анализы демо (1/3), сравнения профилей (5), снимки прогресса (3). Сумма всех наград недели — 620 очков, недельный кап — 650.
2. **События** — каждое действие засчитывается как `MissionEvent` с уникальным `(user, type, ref)` → идемпотентность. Демо-анализы и снимки засчитываются автоматически (хуки в модулях), сравнения — из JS, победы — по кнопке «Засчитать» через сканирование истории матчей привязанного профиля.
3. **Очки** — начисление пишется в immutable-леджер `points_ledger` с причиной и балансом после операции.
4. **Месячный цикл** — при первом запросе нового месяца прошлые месяцы закрываются лениво: топ-100 фиксируется в `monthly_standings`, топ-5 получает награду со статусом `pending`, все балансы обнуляются записью `-balance` в леджер.
5. **Награды** — Faceit Premium для топ-5. ⚠️ Публичный API Faceit не позволяет стороннему сервису активировать подписку на чужом аккаунте, поэтому сервис готовит очередь с faceit_id получателя, а оператор активирует вручную (`POST /api/missions/rewards/activate`, только админ) и фиксирует статус `activated`. Всё остальное (определение победителей, очередь, архив) — автоматическое.

**Анти-абьюз:**
- Идемпотентность событий (UniqueConstraint в БД + повторная проверка)
- Дневные капы: 12 побед / 5 демо / 10 сравнений / 3 снимка
- Burst-детект побед: ≥8 побед за < N×25 мин → событие `flagged`, не идёт в зачёт
- Недельный кап очков (650)
- Кулдаун сканирования матчей — 10 минут
- Сравнения: пара нормализуется (A|B ≡ B|A), дедупликация по паре
- Аудит: каждое начисление в леджере с причиной и ссылкой на источник

### Анти-DDoS

- Глобальный лимит: 60 req/min/IP на все `/api/*` (настраивается `RATE_LIMIT_PER_MINUTE`).
- Логин: 5 попыток / 15 мин / IP (`RATE_LIMIT_LOGIN_PER_15MIN`).
- Регистрация: 5 / час / IP. Капча: 10 / мин / IP. Контакты: 5 / час / IP.
- Математическая капча (TTL 5 мин): включена всегда, если `CAPTCHA_ENABLED=true`; дополнительно принудительно включается после 3 неудачных логинов с одного IP.
- Все попытки входа логируются в таблицу `login_attempts`.

> Для продакшена рекомендуется: Redis вместо in-memory хранилища, реверс-прокси (nginx/Cloudflare) с WAF, HTTPS.

## Установка и запуск

### Быстрый старт (один скрипт)

```bash
# Linux / macOS
./start.sh

# Windows
start.bat
```

Скрипт сам создаст `.venv`, установит зависимости и запустит сервер.

### Вручную

```bash
cd faceit-analytics
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env    # при желании заполните FACEIT_API_KEY

uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Откройте **http://localhost:8000**. Интерактивная документация API — **http://localhost:8000/docs**.

## Деплой в интернет (для «общих масс»)

Подробная инструкция — в **[DEPLOY.md](DEPLOY.md)**. Кратко:

- **Render.com** (бесплатно): загрузите код в GitHub → New Web Service → Render сам соберёт образ из `Dockerfile` → получите публичную ссылку. ~10 минут.
- **VPS + Docker**: `docker compose up -d --build` на любом сервере с Ubuntu.

```bash
# Локальный запуск через Docker (проверка перед деплоем)
docker compose up -d --build
# → http://localhost:8000
```

⚠️ Перед выходом в интернет обязательно смените `SECRET_KEY` и подумайте о постоянном хранилище для БД (на бесплатном тарифе Render диск сбрасывается при каждом деплое).

## Переменные окружения (.env)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DATABASE_URL` | `sqlite:///./faceit_analytics.db` | Строка подключения БД |
| `SECRET_KEY` | dev-заглушка | Ключ подписи JWT — **обязательно смените** |
| `FACEIT_API_KEY` | пусто | Ключ Faceit Developer API. Без него — **demo-режим** со синтетическими данными |
| `FACEIT_CACHE_TTL` | `300` | Кэш ответов Faceit API, сек |
| `AI_API_KEY` / `AI_BASE_URL` / `AI_MODEL` | пусто | Внешний OpenAI-совместимый LLM для глубокого разбора демо. Без них — локальный эвристический движок |
| `DEMO_ANALYSIS_PRICE` | `99.0` | Цена платного анализа, ₽ |
| `FREE_DEMO_ANALYSES` | `1` | Сколько бесплатных анализов у нового пользователя |
| `RATE_LIMIT_PER_MINUTE` | `60` | Глобальный лимит запросов/IP/мин |
| `RATE_LIMIT_LOGIN_PER_15MIN` | `5` | Лимит попыток входа/IP/15 мин |
| `CAPTCHA_ENABLED` | `true` | Всегда требовать капчу при входе |
| `CAPTCHA_TRIGGER_THRESHOLD` | `3` | Насколько неудачных логинов до принудительной капчи |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | `1440` | Время жизни JWT |
| `DEBUG` | `false` | Режим отладки uvicorn |
